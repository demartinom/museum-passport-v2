| Field         | Meaning                                          | Met Equivalent    |
| ------------- | ------------------------------------------------ | ----------------- |
| id            | The object ID in database                        | met-{objectID}    |
| museum        | shortened museum name                            | met               |
| source_id     | original id                                      | objectID          |
| title         | Name of artwork                                  | title             |
| artist        | Name of artist                                   | artistDisplayName |
| date_display  | Date as shown to visitors                        | objectDate        |
| date_begin    | Earliest year, number                            | objectBeginDate   |
| date_end      | Latest year, number                              | objectEndDate     |
| url           | Link to page on museum website                   | objectURL         |
| image_large   | Main image                                       | primaryImage      |
| image_small   | Thumbnail image                                  | primaryImageSmall |
| medium        | What medium the art was made with (may not keep) | medium            |
| public_domain | Image is open access                             | isPublicDomain    |
